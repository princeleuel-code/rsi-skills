# RSI Daily Growth Loop

## When to Use
For an authorized domain's scheduled growth cycle.

## Procedure
DISCOVER → MODEL → OBSERVE → VERIFY → DIAGNOSE → PRIORITIZE → PROPOSE → CHALLENGE → GOVERN → EXECUTE → VERIFY EXTERNAL STATE → MEASURE → ATTRIBUTE → LEARN → PROMOTE OR ROLL BACK.

## Pitfalls
- Do not equate ranking movement with established causation.
- Do not execute without a valid ActionContract.
- Do not treat a generated creative as evidence.
- Do not create uncontrolled continuous editing.

## Verification
Every executed action has a signed receipt, postcondition check, measurement window, and rollback state.
