# RSI Candidate Learning

## When to Use
After a mission reveals a durable reusable lesson.

## Procedure
1. Capture provenance and tenant scope.
2. Remove customer-sensitive information before platform learning.
3. Create CandidateMemory, CandidateSkill, CandidatePrompt, CandidatePolicy, CandidateWorkflow, or CandidateModelRoutingRule.
4. Run schema, static, fixture, adversarial, isolation, authorization, rollback, shadow, canary, and outcome gates.
5. Promote only through a signed receipt.

## Pitfalls
- Do not directly modify production memory or skills.
- Do not generalize one customer's private facts.
- Do not promote based solely on model preference.

## Verification
Candidate state, gate receipts, promotion signer, and rollback reference are all present.
